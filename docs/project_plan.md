# Brain Tumor MRI Classification

## Objective
Develop a deep learning model to classify brain MRI images into:
- Glioma
- Meningioma
- Pituitary
- No Tumor

## Dataset
7200 MRI images

## Model
EfficientNetB0

## Evaluation
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
